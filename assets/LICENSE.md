# Recursos originales

Los PNG de esta carpeta se generaron para ELDRITCH-404 mediante `tools/art.py`. Se distribuyen bajo los términos de la licencia MIT incluida en el proyecto. La composición y la síntesis programática de sonido de `src/audio.mjs` también son originales. No se distribuyen fuentes, muestras, grabaciones ni recursos de otros videojuegos. El motor usa las APIs del navegador. Pillow, Playwright y Canvas de Node son herramientas opcionales de producción y pruebas y conservan sus propias licencias.

La portada `title-cinematic.webp` se generó para esta entrega de ELDRITCH-404 a partir de una descripción original y se optimizó a JPEG. No incluye material de una obra cinematográfica existente.
